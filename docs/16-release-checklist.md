# 16. Release Checklist

Финальный чек-лист готовности к промышленной эксплуатации. Все пункты
подтверждены на этапе технического аудита (без изменения функциональности).

## Качество кода и архитектуры

- [x] `npx tsc` — 0 ошибок.
- [x] `--noUnusedLocals/Parameters` — чисто в клиентском коде.
- [x] `npx vite build` — без предупреждений; все чанки < 500 КБ.
- [x] `madge --circular` — циклических зависимостей нет (клиентский код).
- [x] Нет `TODO/FIXME/console.*/debugger/any/!` в клиентском коде.
- [x] MVVM / SOLID / DRY / KISS соблюдены; единая feature-first структура.
- [x] Движок расчёта идентичен `main` (диф пуст) — заморожен.

## Функциональность (регрессия)

- [x] Полный производственный цикл: приём → склад → работа → расчёты → переход
      <порога → закрытие → архив.
- [x] Отчёты (8 видов), PDF (печатный HTML), e-mail (симулированный транспорт).
- [x] Аналитика/KPI; центр решений (уведомления, прогнозы, качество, поиск).
- [x] Резервное копирование / восстановление (round-trip); целостность.
- [x] Smoke-регрессия — 10/10 (документирована в CHANGELOG «Этап 13»).

## UI / UX / доступность

- [x] Единая Design System (токены, без магических чисел и прямых системных цветов).
- [x] Light / Dark режимы (семантические токены).
- [x] Accessibility: VoiceOver (aria/role), Dynamic Type (rem), Reduce Motion,
      Increase Contrast, forced-colors.
- [x] Тактильная отдача только для значимых действий, подавляется при Reduce Motion.

## Релиз (PWA)

- [x] `manifest.webmanifest` (standalone, ru, иконки, тема).
- [x] `index.html`: `title`/`description`/`theme-color`/apple-теги/`apple-touch-icon`.
- [x] `appInfo.version/build/bundleId` (экран «О приложении»).
- [x] Приватность: разрешения устройства не запрашиваются; данные — только
      локально (`localStorage`); работа офлайн.

## Известные ограничения (не блокируют эксплуатацию)

- PDF — печатный HTML (не бинарный PDF); e-mail — симулированный транспорт;
  рассылка по расписанию — при запуске приложения, не в фоне.
- Хранилище — `localStorage` (объём ограничен браузером); для больших объёмов —
  переход на IndexedDB (протокол готов).
- Экраны ещё используют базовую библиотеку компонентов; перевод на новые
  Card-First компоненты (JumboCard/RingProgress/Timeline и т.д.) — плановые
  этапы миграции.
- Заготовки под будущие версии: CSV/Excel-экспорт, импорт, облачная синхрони-
  зация, английская локаль, реальные коннекторы интеграций.

## Рекомендации по тестированию

- Прогонять автономные `.mts`-harness'ы (in-memory `KeyValueStore` +
  `createAppContainer`) через `npx tsx` для регрессии полного цикла и объёмов.
- Ручная проверка Light/Dark, Dynamic Type (крупный шрифт), VoiceOver и офлайн-
  запуска на целевом устройстве.
- Нагрузочная проверка на объёмах (1000 Джамбов, 100 000 операций) —
  диагностика/скан/копия в пределах долей секунды.

## Рекомендации по публикации

- Как **PWA** приложение готово к установке (манифест + офлайн + apple-теги).
- Для публикации как **нативного** iOS-приложения в App Store — обёртка
  (Capacitor/PWA-упаковка): Bundle Identifier (`appInfo.bundleId`),
  Version/Build (`appInfo`), App Icon, Launch Screen, Release Configuration =
  production-сборка Vite. Это оформление, не доработка кода.
