# 15. Центр решений (Intelligence, v2.0)

Модуль `client/src/intelligence/` превращает приложение из системы учёта в
систему поддержки принятия решений. Все движки — **чистые функции** над единым
агрегатором `ReportContext` (как `KpiEngine`), без доступа к хранилищу и без
пересчёта истории; результат кэшируется по сигнатуре данных.

## Состав

```
intelligence/
├── models/        Notification, Forecast, Quality, Recommendation, Search, SettingsChange
├── engine/        NotificationEngine · ForecastEngine · QualityEngine · RecommendationEngine
├── services/      IntelligenceService (оркестрация+кэш) · SearchService · SettingsHistoryService
├── integrations/  IntegrationProvider (ERP/1С/SAP/REST/CSV — протоколы-заготовки)
├── viewmodels/    useNotifications · useDecisions · useSearch · useSettingsHistory
├── views/         NotificationCenter · Decisions · Search · SettingsHistory · Integrations
└── intelligenceCenter.ts · index.ts
```

## Возможности

- **Центр уведомлений** — 7 правил над данными: низкий остаток Джамба
  (<порога → High, <½ → Critical), материал заканчивается/закончился, высокий %
  отходов, простой Джамба (>14 дн.), ошибки отправки отчётов, устаревший бэкап,
  превышение потерь. Каждое: важность (Critical/High/Medium/Low), дата, описание,
  рекомендуемое действие, статус (new/seen/done). Статус персистентен по
  детерминированному id; остальное пересчитывается из данных.
- **Прогнозирование** — дата окончания Джамба, расход материала, потребность в
  Джамбах на 30 дней, загрузка станков/операторов (прозрачные экстраполяции
  средних).
- **Контроль качества** — доля отходов по материалам/операторам/станкам +
  технологический остаток; подсветка аномалий.
- **Рекомендации** — подготовить Джамб, заказать материал, проверить станок,
  запланировать ТО, проверить сырьё.
- **Глобальный поиск** — по Джамбам, заказам, материалам, операторам, документам,
  архиву (~20 мс на 5000 Джамбов).
- **История изменений настроек** — кто/что/когда/старое→новое (PIN маскируется).
- **Интеграции** — определены только протоколы `IntegrationProvider` для
  ERP/1С/SAP/REST/CSV; коннекторы — заготовки, подключаются реализацией
  интерфейса без изменения бизнес-логики.

## Переиспользование данных

Модуль не вводит новых источников данных: notifications/forecast/quality/
recommendations строятся из `ReportContext` (тот же агрегатор, что у отчётов и
аналитики), а поиск и история настроек читают существующие репозитории/хранилище.
Новые storage-ключи (`notificationStates`, `settingsHistory`) включены в бэкап.
