# 18. Roadmap развития проекта

Все пункты — расширения на подготовленных точках; ядро (алгоритм расчёта,
доменные модели, слоистая архитектура) остаётся стабильным.

## Ближняя перспектива

- **Экспорт CSV/Excel** — реализовать провайдеры (интерфейсы и реестр уже
  есть; сейчас заготовки `available:false`).
- **Импорт данных** — сырьё, справочники, настройки (провайдеры-заготовки
  готовы).
- **Английская локализация** — наполнить оверрайд `en` в `resources/i18n.ts`
  и добавить переключатель языка в настройках (fallback на русский уже
  работает).
- **Автобэкап по расписанию** — включить фактическую периодическую копию
  (флаг `autoBackup` и метки уже есть).

## Средняя перспектива

- **IndexedDB-бэкенд** `KeyValueStore` — для больших объёмов и индексов;
  вышележащие слои не меняются. Устраняет O(n²) массового `receiveBatch`.
- **Миграции схемы БД** по `DB_VERSION` — включить механизм при первом
  несовместимом изменении моделей.
- **Биометрия и автоблокировка по таймеру** — задействовать поля безопасности
  настроек.
- **Самостоятельные иконки 192/512 (maskable) и Service Worker** — полный
  офлайн-PWA; самостоятельный хостинг шрифтов (сейчас Google Fonts с
  системным фолбэком).

## Дальняя перспектива

- **Облачная синхронизация и многопользовательский режим** — реализовать
  облачный `StorageProvider` (интерфейс есть) и роли `User` (модель есть);
  бизнес-логика не меняется.
- **Реальный e-mail-транспорт** (SMTP/API-шлюз) вместо симулированного —
  замена `EmailTransport` без изменения вызывающего кода.
- **Нативная упаковка** (Capacitor) для публикации в App Store как нативного
  приложения и генерация бинарного PDF.

## Технический долг / известные ограничения

- PDF = печатный HTML (не бинарный PDF).
- E-mail = симулированный транспорт (нет реальной доставки).
- Планировщик рассылки работает при запуске приложения, а не в фоне.
- `receiveBatch` ~O(n²) по размеру одной партии (незаметно для реальных
  партий; критично только при массовом импорте тысяч записей за раз).
- Хранилище — `localStorage` (объём ограничен браузером; для роста — IndexedDB).
