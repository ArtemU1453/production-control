# Release Notes

## v1.0.0 (build 1) — первый релиз

Первый производственный выпуск приложения «Калькулятор нарезки» —
промышленный учёт нарезки рулонных материалов (Джамбов).

### Возможности

- **Расчёт нарезки** — оптимальный раскрой по полезной ширине (алгоритм
  заморожен и проверен).
- **Склад Джамбов** — приём партий, полный жизненный цикл (на складе → в работе
  → подлежит списанию → архив), транзакционное списание остатка.
- **Производственные сессии** — заказы, рулоны (в заказ / на склад), журнал
  операций.
- **Отчёты** — 7 видов, PDF (печатный HTML) и рассылка по e-mail
  (симулированный транспорт), история и повторная отправка.
- **Аналитика / KPI** — производственные показатели, графики, сравнение
  периодов.
- **Центр решений (v2.0)** — уведомления, прогнозы, контроль качества,
  рекомендации, глобальный поиск, история изменений настроек.
- **Администрирование** — журналы ошибок/аудита, пользователи, резервное
  копирование/восстановление, обслуживание базы, диагностика.
- **Интерфейс** — Design System уровня Apple, Light/Dark, доступность
  (VoiceOver, Dynamic Type, Reduce Motion, Increase Contrast), тактильная отдача.

### Конфигурация

- Версия: `1.0.0`, сборка: `1`, идентификатор: `com.narezka.calculator`
  (`resources/appInfo.ts`).
- PWA: `manifest.webmanifest` (standalone, портрет, ru, тема light/dark),
  apple-mobile-web-app-теги, `apple-touch-icon`.
- Приватность: приложение **не запрашивает разрешений устройства**, работает
  офлайн, данные — только локально (`localStorage`).

### Известные ограничения

- PDF — печатный HTML (не бинарный PDF); e-mail — симулированный транспорт;
  рассылка по расписанию выполняется при запуске приложения.
- Хранилище — `localStorage` (объём ограничен браузером).
- Иконка-ассет — единый `favicon.png` (128×128); для сторов рекомендуется
  добавить набор PNG 192/512 (maskable) — ассет-задача, кода не касается.
- Экраны используют базовую библиотеку компонентов; перевод на новые
  Card-First компоненты — плановые этапы миграции.
- Заготовки будущих версий: CSV/Excel-экспорт, импорт, облачная синхронизация,
  английская локаль, реальные коннекторы интеграций.

### Публикация

- Как **PWA** приложение готово к установке (манифест + офлайн + apple-теги).
- Для публикации как **нативного** iOS-приложения в App Store требуется обёртка
  (Capacitor / PWA-упаковка): Bundle Identifier (`appInfo.bundleId`),
  Version/Build (`appInfo`), App Icon, Launch Screen, Release Configuration =
  production-сборка Vite. Это оформление, не доработка кода.
