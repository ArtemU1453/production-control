# 12–13. Архивирование и резервное копирование

## Архивирование

Закрытие Джамба (`WarehouseService.closeJumbo`) переводит его из активного
склада в архив как самодостаточный **снимок** `ArchivedJumbo`:

- финальная копия `jumbo` (с итоговыми накопителями);
- собственные `sessions[]`, `operations[]`, `wastes[]` на момент закрытия;
- **замороженная** `statistics` (`ArchivedJumboStatistics`): общая/полезная
  площадь, брак, технологический остаток, суммарные потери и их проценты,
  использованная длина, начальная намотка, финальный остаток, число заказов/
  рулонов/операций, эффективность.

Перед закрытием фиксируется технологический остаток как запись `Waste`.
Статистика архива никогда не пересчитывается — это гарантирует стабильность
исторических отчётов независимо от последующих изменений справочников.

Экран «Архив» даёт поиск и фильтры, «Карточка архива» — детальный отчёт по
Джамбу (`ReportBuilder.buildJumboReport`). Архив участвует в отчётах и
аналитике (потери, эффективность за период).

## Резервное копирование

Сервис `admin/services/BackupService.ts`.

### Создание копии

`createBackup()` читает все коллекции из `backupStorageKeys` и формирует
`BackupData { version, appVersion, createdAt, data }` — единый JSON-снимок
(Джамбы, материалы, сессии, операции, потери, архив, документы, журналы,
пользователи, настройки). Обновляет `backupMeta.lastBackupAt` и пишет запись
аудита.

### Экспорт/импорт файла

- `exportJson()` — сериализует снимок; UI отдаёт его как файл (`Blob` →
  скачивание).
- `importJson(json)` — `JSON.parse` + строгая проверка `isBackupData`
  (некорректный формат отклоняется) → `restore`. Ошибка показывается тостом.

### Восстановление

`restore(backup)` проверяет версию (`version ≤ BACKUP_VERSION`) и записывает
каждую коллекцию обратно; обновляет `backupMeta.lastRestoreAt` и пишет аудит.
После восстановления UI просит перезагрузить приложение.

### Провайдеры и заготовки

- **StorageProvider**: локальное хранилище активно; облачное — заготовка того
  же интерфейса.
- **Export**: JSON рабочий; CSV/Excel — заготовки (`available:false`).
- **Import**: сырьё/справочники/настройки — заготовки под будущие версии.

Все операции резервного копирования, восстановления и обслуживания фиксируются
в журнале аудита.
