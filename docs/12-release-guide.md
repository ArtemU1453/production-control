# 17. Инструкция по выпуску новых версий

## Версионирование

- Семантическая версия и номер сборки — в `resources/appInfo.ts`
  (`version`, `build`, `bundleId`). Отображаются на экране «О приложении».
- Версия схемы БД — `DB_VERSION` (`DiagnosticsService`).
- Версия формата резервной копии — `BACKUP_VERSION`.

## Чек-лист релиза

1. Обновить `appInfo.version` и `appInfo.build`.
2. При изменении моделей — проверить обратную совместимость; при
   несовместимости поднять `DB_VERSION` и добавить миграцию.
3. Прогнать проверки сопровождения (tsc, unused, build, отсутствие «запахов»,
   неизменность движка расчёта).
4. Прогнать проверочный harness (полный цикл + edge-cases + нагрузка) — все
   проверки зелёные.
5. Обновить `CHANGELOG.md` (новый раздел с изменениями и результатами
   проверок).
6. Собрать релиз: `npx vite build` → артефакты в `dist/public/`.
7. Проверить PWA-манифест (`client/public/manifest.webmanifest`) и метатеги
   `index.html` (title, description, theme-color, apple-теги, иконки).
8. Тег/релиз в репозитории; публикация артефактов.

## App Store / упаковка

Готовность как **PWA**: манифест (standalone, ru, иконки, тема), офлайн-работа,
`apple-mobile-web-app`-теги, `apple-touch-icon` — приложение устанавливается
на устройство.

Приватность: приложение **не запрашивает разрешений устройства**, работает
офлайн и хранит данные только в `localStorage` — эквивалент «пустого» Privacy
Manifest; описания разрешений (Permission Usage Description) не требуются.

Для публикации именно как **нативного** iOS-приложения в App Store нужна
обёртка (Capacitor / PWA-упаковка), внутри которой задаются Bundle Identifier
(`appInfo.bundleId`), Version/Build (`appInfo`), App Icon и Launch Screen, а
Release Configuration = production-сборка Vite. Это оформление, не изменение
кода.

## Откат

Резервная копия (`admin/backup`) — механизм отката **данных**. Откат **кода** —
через git (возврат к предыдущему тегу) и повторная сборка. Форматы копий
версионированы (`BACKUP_VERSION`), восстановление более новой копии на старую
версию отклоняется.
